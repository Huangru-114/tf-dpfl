# exp006 — badpfl × fedrep × resnet10，「对齐论文 fraction/poison」的尝试（判决：**无效，前提不成立**）

- **配置（仓库内）**：`full_p4_resnet.yaml` = 100 client / 2 edge / 10 mal(spread) / cifar10 /
  hier_fedrep / defense=none / resnet10(BN) / **client_fraction=0.1 / poison_ratio=0.2** / 80 round。
- **metrics**：`exp006.metrics.json`
- **动机**：exp004 结论是「过度参与/过度投毒把主任务打崩」。本 run 意在把 fraction、poison
  降到论文值（0.1 / 0.2），看 acc 是否回到 ~0.72、asr 是否仍高。

## 表面结果

| final | GM_ASR | EM_ASR | local_malicious | local_benign | same_edge | diff_edge | pm_acc |
|---|---|---|---|---|---|---|---|
| r80 | 0.969 | 0.959 | 0.916 | 0.440 | 0.440 | **0.000** | **0.4156** |

benign 从 r20 起就卡在 0.41~0.44（无平台上升）；pm_acc 卡 0.41（干净基线 0.72，论文 0.80）。
表面看：「对齐 fraction/poison 依然 acc 崩 + benign 迁移失败」。

## ⚠️ 判决：这个结论**前提不成立** —— exp006 实际没有跑在 client_fraction=0.1 上

**数值反证（可复算）**：
- `select_clients`（`server/edge_server_base.py:90-101`）每个 edge_round 从本 edge 客户端
  无放回抽 `int(len×frac)` 个；edge RNG（`:43`）一次创建、跨调用推进 → 真随机抽样。
- 100 client / 2 edge → 每 edge 50 个；frac=0.1 → 每 edge_round 抽 5/50，单恶意端单
  edge_round 命中率 0.1；每 global round 5 个 edge_round → 命中率 ≈ 1−0.9⁵ ≈ **0.41**。
- 单恶意端出现在全部 80 轮的概率 ≈ 0.41⁸⁰ ≈ 10⁻³¹；10 个全部 × 全部 80 轮 → 实际为 0。
- 但 `exp006.metrics.json` 的 `malicious_participation_by_client` 显示 **10 端 × 全部 80 轮**
  （`n_malicious_participations: 80`）。

→ 只可能对应**有效 fraction ≈ 1.0（全参与）**。没有任何 force-inject 恶意端的代码路径
（`server.py` / `main.py` 均无）。结合 08-22 交接的「集群 config 改了没 push」漂移警告，
判定：**exp006 跑的 fraction 不是 0.1**，投毒强度约为标称的 10×，与 exp004 同类。
「对齐 fraction 也没用」这个科学结论**目前不成立**。

**为什么没被发现**：`metrics.json` 的 `run` 块此前只记 method/defense/attack/n_rounds/
malicious_ids，**恰恰不含 client_fraction / poison_ratio**（陷阱 #7 的同类）。你说「改成
论文值」的两个旋钮，正好是 artifact 里看不见的两个 → 无法证实。

## 两条次要澄清（避免误判，非 bug）

- **diff_edge=0.0 是布点/度量假象**：`attack/backdoor_eval.py:130-167` 里 `malicious_edges`
  = 含≥1 恶意端的 edge 集合；benign 端所在 edge ∈ 该集合算 same_edge，否则 diff_edge。
  只有 2 edge + 10 恶意端 spread → **两个 edge 都含恶意** → 没有任何 benign 是 diff_edge
  → `_mean([])=0`。这也解释每轮 `same_edge == local_benign` 完全相等。
  **含义：当前 config 下跨 edge 迁移性根本没被测到**，不能读成「跨 edge 迁移=0」。
- **acc 崩溃指纹**：log_tail 混淆矩阵显示所有类塌向**类 3**（非后门目标类 9）→ 是主任务被
  打坏，与「共享 backbone 被过度投毒污染特征、殃及所有个性化模型」一致，正是全参与的后果。
