## 结论 1：陷阱 #1 已修复，但**它不是 pFedMe 下 GM_ASR≈0 的原因**

这正是 2×2 设计出来要回答的问题，答案是干净的排除法：

**badnet 用的是 vanilla 策略，`select_attack_mixin` 返回 None，
从来就没走过陷阱 #1 那条「攻击类替换方法类」的代码路径** —— 它在改动前后走的是同一条路。
而 `badnet × hier_pfedme` 的 GM_ASR 是 **0.000**，和 `neurotoxin × hier_pfedme` 的 0.009 同量级。

→ pFedMe 下 GM_ASR≈0 与攻击轴无关，是**方法轴**的性质。
陷阱 #1 修好之后，这个现象仍然在，且现在**可解释**了。

## 结论 2：真实原因是 pFedMe 的全局模型 5 轮内几乎没学到东西

逐轮 GM acc：

```
101/103 hier_fedavg   0.33 → 0.51
102/104 hier_pfedme   0.09 → 0.19      ← CIFAR-10 随机基线 = 0.10
```

**全局模型的分类准确率只有 0.19，勉强高于随机。在一个几乎没训练的模型上量后门成功率，
数字没有意义。** GM_ASR = 0 是「全局模型是空的」的推论，不是「攻击失败」的证据。

成因与**陷阱 #8** 直接相关：cloud 层聚合的是 edge 上传的 Moreau 锚点 `W_n`，
它每轮只走 `η1·λ1` 一小步；而 cloud 层的方法专属聚合分支全被注释掉，
`beta_hier`（式 9 的 β）是死配置 —— 全局模型没有任何加速收敛的机制。

> **给后续会话的判读规则**：pFedMe 系方法下，**GM_ASR 不是有效指标**，
> 要看 EM / local ASR。用 GM_ASR 比较 fedavg 与 pfedme 等于在比较两个不同的东西。

## 结论 3：pFedMe 下后门确实存在于 edge 与 local 层

EM ASR ≈ 0.22，local_benign ASR ≈ 0.14–0.18，都远高于噪声。攻击是生效的。

而且 EM ASR 的**趋势方向相反**，这是本次数据里最值得追的一条：

```
101 hier_fedavg  0.407 0.447 0.440 0.473 0.534   ↑ 上升
102 hier_pfedme  0.269 0.252 0.231 0.226 0.223   ↓ 下降
103 hier_fedavg  0.297 0.293 0.264 0.325 0.414   ↑ 上升
104 hier_pfedme  0.281 0.252 0.244 0.227 0.220   ↓ 下降
```

两个攻击下都是同一个方向：**hier_fedavg 的边缘后门逐轮累积，hier_pfedme 的逐轮衰减。**
若这个趋势在更多轮下保持，就是「个性化 = 隐式防御」的证据 —— 但
**5 轮太短，现在还不能下这个结论**，需要 40 轮的 run 才谈得上。

## 结论 4：Neurotoxin 弱于普通 badnet（与陷阱 #4 的预期一致）

同为 hier_fedavg：GM_ASR 0.364（neurotoxin）vs 0.635（badnet），EM 0.414 vs 0.534。

当前实现的语义是「屏蔽 benign 梯度幅值 **top-5%** 的坐标、放行其余 95%」，
即「badnet 减掉最有影响力的那 5% 坐标」→ 比 badnet 略弱，**与观测一致**。
若官方语义是反的（只**保留** |g| 最小的 5%），Neurotoxin 会比这弱得多。

> 这条数据**不能证伪也不能证实陷阱 #4** —— 它只是说明当前实现的行为与其代码语义自洽。
> 方向问题仍需 clone 官方实现核对。
