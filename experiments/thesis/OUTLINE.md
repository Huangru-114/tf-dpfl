## 一、提纲

### 第 1 章 引言
- 场景：机构对应边缘服务器（医院 / 区域），机构内客户端个性化；三层联邦学习的云端只看到边缘聚合。
- 问题：优化型个性化后门（Bad-PFL）在这种结构里怎么扩散、边缘服务器能做什么。
- 空白：分层联邦学习的安全研究只用弱威胁（标签翻转、固定方块）、不带个性化；个性化后门研究都不分层（文献综述，`experiments/defense/edge-native/LITERATURE.md` 第 1、3 部分）。
- 三个研究问题与贡献（见 `INTEGRATION-PLAN.md` 第一、六节）。

### 第 2 章 背景
- 三层联邦学习；FedRep（共享主干 + 私有分类头，本仓库另把批归一化运行统计量设为私有）。
- Bad-PFL：触发器 = 生成器给出的定向扰动 + 一步非定向扰动，总幅度 ≤ 8/255；原文消融（定向部分是主体）；原文里已知防御基本失效（Bad-PFL 原文表 2 / 3 / 21，摘录在 LITERATURE 2.1）。
- **阶段一**（另一个仓库、官方代码、不分层）：攻击刻画的起点，简述 —— 用户提供数字与图。
- 威胁模型：边缘服务器可信、持 500 张干净图且保密；攻击者控制 10% 客户端；主实验不知道防御。

### 第 3 章 相关工作
- 分层联邦学习的后门 / 投毒防御（SHIELD、RoHFL、FLVaccin、Al-Maslamani、Alqattan 两篇）。
- 个性化联邦学习的后门（Bad-PFL、PFedBA、ACISP 2026 两层「end–edge」；部分共享的鲁棒性：Qin 等 KDD 2023 与 Simple-Tuning）。
- 统计量检测（BNGuard、CCS、BNP）与参照式信任（FLTrust、FoggyTrust、SURA）。
- 边缘级个性化（ESPerHFL、HPFL 等，只为精度）。只投毒关键层的攻击（ICLR 2024）作为会适应攻击者的模板。

### 第 7 章 讨论
- 杠杆在机构边界：三条防御线都只在「攻击者集中 + 受害边缘」有效；攻击者所在边缘与分散布点 = 边缘内部的不分层问题，Bad-PFL 原文里已知防御基本失效。
- 隔离不是清除；威胁模型的现实性（集中布点对应被攻陷的机构）；会适应的攻击者；离线读数高估在线效果（加固的离线筛选、参照打分各一次）。
- 局限：单一数据集与模型、攻击接近饱和、评估口径（个性化模型 vs 客户端旧模型的精度）、三层个性化下全局模型不完整、主结论 3 个种子、部分判定脚本写于数据之后（规则在前）。
