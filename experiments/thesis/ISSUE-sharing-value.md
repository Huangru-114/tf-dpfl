# 待议问题：云端共享（三层结构本身）的价值在本设定下偏小（2026-11-23 记录，未决）

> 来源：补充实验 D1 块数扫描（F-130）回传后用户提问：「几乎断开云端共享也只差约 0.02 精度，三层联邦学习结构本身的存在价值是什么？」
> 状态：**只记录、不排期**（用户 11-23：「这还不是最需要做的」）。下面的「推测」都没有数据，写论文前不能当结论用。

## 一、数据说明了什么

集中布点、现主线划分、3 个种子均值（F-130）：

| 隔离块数 B | 上云参数比例 | 受害边缘攻击成功率 | 个性化精度 | 相对全共享的精度代价 |
|---|---|---|---|---|
| 0（全共享） | 100% | 0.996 | 0.868 | — |
| 1（三层个性化） | 25.1% | 0.281 | 0.867 | 0.002 |
| 2 | 6.4% | 0.046 | 0.859 | 0.010 |
| 4（几乎断开，只剩输入层上云） | 0.14% | 0.027 | 0.846 | 0.022 |

- 跨边缘共享值约 0.02 精度（≈ 项目自己的「可接受代价」门槛），不是零，但不大；它同时是后门跨边缘传播的通道（0.027 → 0.996）。
- B=1 几乎保住全部共享收益（代价 0.002），但「B=1 比几乎断开多保住的精度」三个种子是 0.018–0.022 → D1 判 inconclusive（预注册 N-015）。
- 预注册时已预见这种可能（D1 的 `isolation_free` 分支：「每个边缘约 9400 张训练图，可能已经够用」→ 写进有效性威胁）。

## 二、为什么共享在这里显得不值钱（推测）

1. **评估只看本地分布**：精度 = 每个客户端在自己留出分片上的 fresh 个性化精度。私有分类头、私有 BN 统计量、边缘内共享的最后一块已把本地分布吃透；共享的价值在本地以外（少数类、分布偏移、新客户端、别的边缘的数据），这些没测，按类精度也没记录。
2. **每台边缘数据充足、任务简单**：约 9400 张训练图、CIFAR-10 只有 10 类。
3. **机构结构偏弱**：边缘层偏斜 r = 0.25（E0 均衡；E1 / E2 / E3 各偏重一对类 25%，同组其余 4 类各 2.5%；airplane / bird / ship / frog 各 10%）；客户端层 Dirichlet α = 0.5 → 同边缘两端的总变差 0.55、跨边缘两端 0.70（比值 0.79），边缘之间只有 0.375（F-125）。每台边缘内部本身就是一个高度非独立同分布的联邦问题。

## 三、上云比例能不能更高（25% 是否太低）

ResNet-10 的参数集中在最后一块（stage4 占 74.9%），按整块切只能在 100% 与 25% 之间二选一。块内再切可以得到中间档：

| 留在边缘的部分 | 上云比例 |
|---|---|
| stage4 的第一个卷积 + shortcut | 约 73% |
| stage4 的第二个卷积 | 约 52% |
| 整个 stage4（现在的 B=1） | 25% |

需要给 `fedavg/utils/tier_split.py` 加按层切的选项（0 块路径不动）。预期（推测）：中间档的受害边缘落在 0.28 与 0.996 之间，取决于后门存在最后一块的哪一层 —— **先看离线探针 P-a（重训最后一块）的结果再定**。

## 四、数据分布推得更极端会怎样

**已有证据**（隔离效果对划分不敏感）：受害边缘在 B=1 下，现主线 0.996 → 0.281、组内更同质（固定画像 λ = 0.4）0.911 → 0.302、旧逐类 Dirichlet 划分 0.81 → 0.29。

**推测**：
- 只加大偏斜、数据量不变：本地任务变简单；全共享可能因异质性受损（甚至不如 B=1）；几乎断开在本地精度上仍可能很便宜 → 「最后一块不上云」更划算，但「云端共享的价值」仍显不出来；隔离可能更强（触发器更难迁移）。
- **偏斜 + 数据稀缺**才最可能显出三层结构的价值：几乎断开学不出好的底层特征，全共享被异质性拖累，B=1 / B=2 成为真正的最优点。
- 工具：层级 Dirichlet 划分（`federation.partition: hdir`，边缘间总变差可到 0.86）已有；α_e 很小时受害边缘可能缺目标类，要固定 airplane 一列。
