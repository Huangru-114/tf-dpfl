## 1. 项目总览

### 1.1 一句话与研究问题

系统是**三层联邦学习**：云（cloud）— 边缘服务器（edge，下称「边缘」）— 客户端（client）。客户端用个性化联邦学习方法 **FedRep**（共享特征主干 + 每个客户端私有的分类头）。攻击是 **Bad-PFL**（ICLR 2025 的个性化后门攻击，触发器是逐样本的小幅对抗扰动）。研究两件事：
- 这种后门在分层结构里**怎样植入、怎样跨边缘传播、攻击者离开后怎样衰减**；
- **边缘**（假设可信、部署在机构内部、持有 500 张干净图片、有算力）能不能成为防御的主角。

**论文的一句话叙事**（用户已确认）：优化型后门是在**云聚合那一刻**跨边缘扩散的（每个云周期「灌入 − 洗掉」的竞赛）；边缘看不出谁在投毒，但它站在云聚合之前、本身是机构边界 → **防御的杠杆在机构之间的边界上，而不在机构内部**。

- **RQ1** 后门在三层结构中怎样植入、扩散、衰减？**RQ2** 边缘能观察到什么、什么时候能干预？（第 5 章）**RQ3** 边缘侧能做什么防御、有效边界在哪、代价多少？（第 6 章）
- **假设**：H1 边缘内更同质 → 边缘视角检测更强 → **否定**；H2 训练后期才开始的攻击更难植入 → **否定**；H3 私有分类头 + 私有统计量能挡住 Bad-PFL → 只有反面信号，写成观察。
- **贡献**（不说「首个」）：C1 机制刻画 + 灌入—洗掉分解；C2 否定结果（边缘视角没有检测优势，最强信号可伪造）；C3 两条非检测型边缘防御（边缘级共享块砍灌入、上传前加固压净增量）+ 一条检测型对照（统计量参照过滤），统一比较并给出有效边界；C4 预注册 + 逐位复现的实验协议、与官方 Bad-PFL 逐条对齐。

### 1.3 最重要的结论

| # | 结论 | 强度 |
|---|---|---|
| 1 | **攻击在本设定下接近饱和**：不设防时攻击者所在边缘的良性端约 0.97–1.0，受害边缘最终也到 0.95 以上；很多效应因此被「天花板」遮住 | ✅（多组一致） |
| 2 | **后门只经云聚合跨边缘传播**：每次云聚合把受害边缘的攻击成功率推高 0.13–0.27；两次云聚合之间受害边缘自己在「洗」（每周期 0.11–0.22），但洗掉追不上灌入 → 一个周期比一个周期高、最终饱和（「锯齿」） | ✅ |
| 3 | **没有「训练后期更安全」的时段**；攻击者离开后约 200 个有效轮褪到底线附近，不分层也一样 | ✅ |
| 4 | **边缘视角没有检测优势**：单个上传的范数 / 余弦 / 功能分数，边缘内归一化与全局归一化一样；唯一强的信号来自 BatchNorm 统计量（AUROC 约 0.90），可零代价伪造（代码证据） | ✅ |
| 5 | **边缘级共享块**（三层个性化：最后 1 个残差块只在边缘内平均、不上云）：攻击者集中时受害边缘 0.996 → 0.281，精度只降 0.002；攻击者所在边缘不受保护；分散布点无效；两种划分都复现 | ✅（旧划分预注册 + 新划分 3 种子） |
| 6 | 它**按边缘隔离**：边缘里有 1 个攻击者就失守（[9,1,0,0]：`clean_protected` + `e1_breached`）；**不只是少共享**的证据是 `inconclusive`（隔离 1 块比几乎不上云多保住 0.018–0.022 精度） | ✅ / 中 |
| 7 | 机制：受害边缘剩下的攻击成功率是**传过去的那部分后门**（白盒探针 `not_transmitted`）；「后门主要存在最后一块」**未能验证**（两次重训探针都定位不了：不打坏模型就清不掉） | ✅ / 无 |
| 8 | **上传前加固**（边缘每云轮末用 500 张干净图做对抗式反学习）：受害端降 0.476 / 0.522 / 0.228，精度降 ≤ 0.015 → `protects_victims`；碰不到攻击者所在边缘；主要靠缩小每周期净增量，不是砍灌入 | ✅ / 🔍 |
| 9 | **CCS**（客户端对抗训练 + 服务端按上传的统计量聚类剔除；只在不分层设置下做）：只开聚类精度代价约 0.01 且稳，但 5 个种子里 2 个失守；对抗训练让训练随机崩溃；统计量检测已有两篇先例 | ✅ |
| 10 | **参照过滤**（边缘用干净集给每个上传打分）：只打分时分得开（AUROC 0.85 / 0.90），在线过滤只把后门压到约 0.5–0.6；组内更同质划分冷启动死锁；分数滞后于后门（反馈循环，离线 108 个边缘模型 Spearman 0.911 → 中等强度证据） | ✅ / 中 |
| 11 | **逐坐标中位数**（边缘层 / 云层）几乎无效：受害边缘只降 0.004–0.105、仍在 0.89–0.99；不砍灌入 | ✅（必须带效应量） |
| 12 | **一句话现状**：没有一种做法同时做到 (a) 分散布点有效、(b) 保护攻击者所在边缘的良性端、(c) 精度代价 ≤ 0.02、(d) 经得起知道防御的攻击者；最便宜也最稳的是边缘级共享块 | — |

## 2. 共同设定与超参数

### 2.1 配置从哪来

每个 run 的配置由固定的链生成，不手写：阶段二的基配置 `experiments/attack/hfl-mechanism/base.yaml` → 叠加**主实验协议模板** `fedavg/config/alignment_p2.yaml`（内部叫「P2 口径」：与官方 Bad-PFL 实现逐条审计差异后定下的全部开关，2026-09-27 定稿；标了 P2 的配置启动时逐键核对，少开一项拒绝启动）→ 各阶段登记表的公共底座与各组的 `set:` → 生成 `configs/<run_id>.yaml`（每 run 一份，用 yaml 原文的 hash 对账）。**只有 P2 口径的 run 进结论**；P0 / P1 是更早的口径，只作背景。

主实验协议模板逐项：

| 开关 | 取值 | 含义 |
|---|---|---|
| 确定性算子 | 开 | TensorFlow `enable_op_determinism()`；每轮打印模型校验和 |
| FedRep 投毒阶段 | 只在主干阶段 | 分类头那段只见干净数据 |
| BatchNorm 统计量 | 私有 | 缩放 / 平移参数共享，滑动均值 / 方差私有（客户端保留自己的副本；**上传里仍带统计量**，见 F-123） |
| 学习率衰减的轴 | 有效轮 | 按「云轮 × 每云轮边缘轮数」衰减，不按云轮（不同 R 之间日程相同） |
| 取数路径 | 每 epoch 重洗 | 每个 epoch 重新打乱、重新增强、丢尾批（旧路径会把增强缓存冻结，3.2% 的样本从未参与训练） |
| 模型 | ResNet-10（torch 对齐） | stride-2 卷积的补边、BN 动量与 epsilon、初始化对齐 PyTorch；BN 推理路径避开 GPU 确定性的坑 |
| 边缘调度 | 交错 | 外层边缘轮、内层各台边缘（共享生成器的更新次序不偏） |
| 参与名额 | 按有效轮轮转 | 每台边缘名额的余数按有效轮轮转 |
| 触发器噪声 ξ | 官方单步 PGD | 随机起点 → 求梯度 → 投影 |
| 评估触发器 | 固定攻击者 | 评估时 ξ 在按种子固定选中的一个攻击者的模型上求（与官方一致） |
| 投毒抽样 | 逐样本伯努利 | 每张样本独立以投毒率决定是否投毒 |
| 生成器 | 照官方 | 结构、初始化、BN 模式 |
| 攻击成功率 | 四列 | 只数非目标类 / 全部 × 只看良性端 / 全部；主指标 = 只数非目标类 × 只看良性端 |
| 评估模型 | 新鲜个性化模型 | 主任务精度与攻击成功率在同一个模型上测（§2.7） |

### 2.2 计算环境与可复现性

- 集群 Arrhenius（瑞典），SLURM 提交，所有 Python 在 apptainer 容器里跑；单卡显存约 96 GiB。
- 一卡并行 3 个同格不同种子的 run（每 run 显存峰值约 17 GiB、4 个 CPU 核、24 GiB 主机内存）；一个三跑包实测 3.9–4.4 小时墙钟（按 1 卡计 GPU 小时）。CCS 格子主机内存约 31 GiB → 一卡 2 个。
- **逐位可复现**：P2 下同配置同种子跨节点、跨作业、跨提交的每轮校验和逐位相同（**前提：每个 run 恰好 4 个 CPU 核**，核数会改变结果）。之后加的每个记录仪表（评估网格、更新几何、在线功能分数、参照打分、只记录模式）都在 GPU 上验证过「开 / 关逐位相同 = 不改变训练」。
- 种子：主检验 42 / 43 / 44（按种子配对）；CCS 线只开聚类补到 45 / 46；参照打分的不投毒开发 run 用 41。
- 机时预算上限约 100 GPU 小时 / 周。

### 2.3 数据与划分

- **数据**：CIFAR-10。官方训练集与测试集合并成 60 000 张后再分给客户端（PFLlib 的做法；划分是一个分割，每张图只属于一个客户端，所以客户端的留出分片与全部训练数据不相交）。
  新划分下每个客户端恰好 500 张 = **375 训练 + 125 留出**（等大小、无放回）。

### 2.4 拓扑、模型与训练

| 项 | 主线（分层）取值 |
|---|---|
| 客户端 / 边缘 | 100 个客户端，4 台边缘 × 25 个，按编号连续分块（E0 = 0–24 号 …） |
| 参与 | 每个边缘轮全局 10%（10 个），每台边缘 2–3 个，余数名额按有效轮轮转 |
| 轮数 | 一个**云轮** = R 个**边缘轮**；**有效轮** = 云轮 × R。阶段三主线 R = 5 × 60 云轮 = **300 有效轮**，固定轮数（自适应停止关）；阶段二部分组用 R = 10 / 20 |
| 聚合 | 边缘内与云端都按样本数加权平均（私有分类头从不上传） |
| 模型 | ResNet-10（torch 对齐）：stem 3×3 卷积 64 通道 + 4 个基本残差块（每段一个，通道 64 / 128 / 256 / 512，后三个 stride 2），全局平均池化，末层 Dense(10, softmax)；最后一段（stage4）约占 74.9% 参数 |
| 个性化 | FedRep，先训分类头再训主干：分类头 1 epoch（约 11 步）、主干 5 epoch（约 55 步）；批 32；SGD 无动量；交叉熵 |
| 学习率 | 主干 0.1 × 0.992^t，分类头 0.005 × 0.992^t，t = 有效轮（第 300 有效轮时主干约 0.009） |
| BatchNorm | 缩放 / 平移共享；滑动统计量私有（动量 0.9 ≈ 最后约 10 批的指数平均）；客户端上传里也带统计量（主干段末尾的值），边缘照样平均，但不下发给客户端 |
| 评估网格 | 每 5 个有效轮一个评估点（主线 = 每云轮末）；第 2 云轮起每次云广播后多一个评估点（算灌入 / 洗掉） |

**CCS 线（不分层）的不同之处**：1 台服务器 × 100 个客户端、每轮 1 个边缘轮 × 300 轮、旧 noniid 划分、模型 = ResNet-10 + 私有投影网络（照 CCS 官方结构：Dense 256 + ReLU → Dense 512 → 分类头，投影与分类头都私有）、每 5 轮一个评估点；多数格子 BatchNorm 统计量**共享**（刻意偏离模板，口径标为 P2-ablation）。FedPer 复现闸用 CCS 官方超参数：每步联合训练全部参数、2 epoch、批 64、学习率 0.1 常数。

### 2.5 攻击：Bad-PFL

| 项 | 取值 |
|---|---|
| 攻击者 | 10 个（全局 10%） |
| 布点 | **集中** [10,0,0,0]：全在 E0（**E0 = 15 个良性端 + 10 个攻击者**，不是全恶意），E1–E3 内部干净 = **受害边缘**，后门只能经云聚合传过去；**分散** [3,3,2,2]：每台边缘都有攻击者；**威胁边界** [9,1,0,0]（只用于补充实验 D2） |
| 投毒率 | 0.2，逐样本伯努利；只在主干训练段投毒；全程投毒（时间窗实验另说） |
| 目标 | 全部到一类：目标类 0（飞机），任何非目标类样本都可被投毒 |
| 触发器 | 触发样本 = x + δ + ξ。δ = 共享生成器输出的**定向**扰动（推向目标类），界 4/255；ξ = 一步**非定向** PGD 扰动（随机起点），ε = 4/255；合计 ‖δ + ξ‖∞ ≤ 8/255（逐样本、肉眼几乎不可见） |
| 生成器 | 全体攻击者共享一个生成器（对齐官方），每轮 30 步、学习率 0.01 |
| 评估 | ξ 在按种子固定的一个攻击者的新鲜个性化模型上求，δ 用共享生成器；攻击成功率只数非目标类 |
| 威胁模型 | **攻击者不知道有防御**（非自适应）——全部防御读数都在这个前提下 |

原文消融（FedRep）：去掉 δ 只剩 12.82%，去掉 ξ 79.32%，两者都在 97.95% → δ 是主体。

### 2.6 各防御的超参数

| 防御 | 作用位置 | 超参数 |
|---|---|---|
| **边缘级共享块**（三层个性化） | 最后 B 个残差块（含 shortcut 与 BN 统计量）= 边缘段：边缘内照常聚合，云聚合时换回聚合前的值，云广播不覆盖 | B ∈ {1, 2, 4} → 上云参数比例 25.1% / 6.4% / 0.14%（B = 1 时上云段 1 227 712 个坐标）；B = 0 = 不设防；只对 FedRep + ResNet-10 开放 |
| **上传前加固**（配置 `sau-e8-train-high`） | 每云轮末、边缘上传前，在边缘模型上做一次 | SAU（共享对抗样本反学习，BackdoorBench 版）：ε = 8/255；BN 训练模式；500 张干净图 × 5 遍（批 32 → 75 步）；每批 5 步对抗；Adam 1e-4（amsgrad）；不增强；参照模型 = 上传前的边缘模型；只改主干，分类头与 BN 统计量写回；约 53 s / 次 |

| **参照打分 / 过滤**（方向 2） | 每个边缘轮，边缘对每个上传 | 上传的可训练权重装进草稿模型，边缘 500 张干净图一整批、训练模式前向，取每个 BN 层输入的逐样本矩，与上传自带的统计量比较；候选分数见 §5.3；每边缘轮 8 个假客户端 × 375 张作零分布；过滤：分数**严格大于** τ 的上传丢弃（权重与统计量都不进平均），本轮全部被丢则边缘模型不变；主划分用类混合残差 τ = 0.119039（不隔离）/ 0.120629（隔离 1 块）；组内更同质划分用逐客户端参照 KL τ = 0.004079 / 0.003728（不投毒开发 run 的 90% 分位点） |
| **逐坐标中位数** | 边缘层（每台边缘 2–3 个上传）或云层（4 个边缘模型） | 无超参数 |

### 2.7 指标与评估口径

| 指标 | 定义 |
|---|---|
| 新鲜个性化模型（论文：评估用个性化模型） | 当前边缘下发的共享主干 + 客户端自己的私有分类头与 BN 统计量。**精度与攻击成功率都在它上面测**。「陈旧个性化模型」= 客户端上次被选中时的模型，只作副列 |
| 良性端攻击成功率（ASR） | 良性客户端的新鲜个性化模型把触发样本判成目标类的比例；只数非目标类、测在客户端自己的留出分片上；**终值 = 末 10 个评估点均值**（阶段三主线 = 第 51–60 云轮） |
| V / B0 / P | V = 受害边缘 E1–E3 良性端（逐边缘平均再平均三台）；B0 = 攻击者所在边缘 E0 的良性端（集中布点下 15 个）；P = 全部良性端池化（分散布点用它） |
| 主任务精度（MTA / pm_acc） | 新鲜个性化模型在客户端自己留出分片上的精度，全部 100 个客户端（含攻击者）按训练样本数加权，末 10 点均值；**精度代价门槛统一 0.02** |
| 底线（floor）/ 超额（excess） | floor = 攻击者在场、生成器照训、一张都不投毒时同一触发器的成功率（对抗扰动本身就能骗过一部分样本），约 0.04–0.13；excess = ASR − floor |
| margin | 触发样本上「目标类对数概率 − 其余类最大对数概率」的中位数；> 0 即多数判成目标类；ASR 贴顶时它仍在动 |
| 灌入 / 洗掉 / 净增量 | 灌入 = 第 g 云轮云广播后的评估点 − 第 g−1 云轮末；洗掉 = 第 g 云轮云广播后 − 第 g 云轮末；净增量 = 灌入 − 洗掉。前半程 = 第 2–30 云轮 |
| AUROC | 某个分数区分「攻击者的上传」与「良性端的上传」的能力：0.5 = 随机，1 = 完全分开 |

- **口径规则**（用户 11-20 定）：两个口径都报（ASR 与 margin 分两行）；标题数字默认 ASR，对照臂在该窗口饱和（≥ 0.95）或两臂都贴底线时改用 margin，所有比较一律照用、不逐图挑。
- ⚠ 新鲜个性化模型里的私有 BN 统计量是分类头段末尾的滑动平均、跟不上之后变化的主干 → **会低估干净精度**（比陈旧模型低 0.011–0.094；快照上只做精确重估就让 E0 良性端第 15 轮精度升 0.075–0.14）。各臂的精度代价同口径相减不受影响；引用精度绝对值时注明。

### 2.8 离线探针的设置（读快照、零训练或短重训）

- **快照**：不设防对照（SNAP）与隔离 1 块存快照的组（TBS k1-snap）在第 6 / 15 / 60 云轮存「上传前的边缘模型 + 全局模型 + 每端私有部分 + 评估攻击者的生成器」，只供评估、不能续训。

- **D3 三个探针**：P-a 在 E0 上只训最后一块 / 只训前面几层 / 训全部主干（沿用 P0 干净微调预算：学习率 = 客户端 × 0.1、75 步）；P-b 在受害者自己的模型上求 ξ（白盒）与评估触发器配对比较；P-c 108 个边缘模型上「同一批干净图加触发器前后的 BN 统计量偏移」与后门强度的秩相关。
- **P-a 追加探针**：只训全部主干，12 档 = 学习率 {0.01, 0.03, 0.1}（固定）× {75, 300} 步 × 分类头 {临时线性头, 重新初始化}；训后 E0 全部 25 端精确重估统计量。

### 4.4 3-C 云周期内的锯齿

规则（写于数据之前）：受害边缘良性端 ASR；灌入 = 云聚合后 − 上一云轮末；洗掉速率 r_down = (云聚合后 − 本云轮末) / R；只取前半程。三个种子都 ≥ 0.005 → `self_cleaning`。

| 格（划分 · R） | r_down a / b / c | 平均灌入 | 每周期洗掉 | 末周期：云聚合后 → 周期末 | 判定 |
|---|---|---|---|---|---|
| C1 · R5 | 0.0388 / 0.0381 / 0.0230 | 0.197 | 0.166 | 1.00 → 1.00 | `self_cleaning` |
| C1 · R10 | 0.0217 / 0.0252 / 0.0201 | 0.268 | 0.223 | 1.00 → 0.98 / 0.85 / 0.97 | `self_cleaning` |

### 4.6 3-D 边缘视角的可观测性

规则：每个上传算几个分数，比较「边缘视角」（本边缘、本窗口内归一化）与「全局视角」（从全部边缘抽同样多个更新当参照，50 次平均）的 AUROC。判读格 = C1 · 分散布点；Δ 都 > 0.05 → `edge_better`；|Δ| 都 < 0.05 → `no_edge_gain`；全局 AUROC < 0.7 → `undetectable`。

| R | 分数 | Δ（边缘 − 全局）a / b / c | 全局 AUROC a / b / c | 判定 |
|---|---|---|---|---|
| 10 | 可训练权重更新范数 | 0.021 / 0.031 / −0.001 | 0.847 / 0.708 / 0.744 | `no_edge_gain` |
| 10 | 与全局其余更新的余弦 | 0.001 / 0.001 / 0.003 | 0.514 / 0.525 / 0.520 | `undetectable` |
| 10 | 与本边缘其余更新的余弦 | −0.003 / 0.003 / 0.004 | 0.617 / 0.614 / 0.597 | `undetectable` |
| 10 | 在线功能分数 | 0.007 / −0.005 / 0.006 | 0.516 / 0.545 / 0.535 | `undetectable` |
| 20 | 权重更新范数 | 0.015 / 0.030 / 0.001 | 0.841 / 0.750 / 0.738 | `no_edge_gain` |
| 20 | 功能分数 | 0.020 / 0.028 / 0.013 | 0.519 / 0.606 / 0.541 | `undetectable` |

（功能分数 c_k = 在边缘干净集上对每个类做定向对抗攻击的失败率，后门会让目标类特别容易被攻到。）
- 误报 5% 时的检出率：权重范数边缘 0.34 / 0.36、全局 0.28 / 0.31（R10 / R20）；功能分数 0.09–0.12；BN 统计量部分约 0.68。
- **范数的可分性主要来自 BN 统计量**（AUROC 0.90–0.91 vs 权重部分 0.74），而统计量通道攻击者可零代价上传干净值（代码证据，没有实验）。
- 集中布点下边缘视角反而更差（🔍）：E0 的上传约 40% 是恶意的，参照池被污染。两份盲算的独立实现 13 个标签全部相同。

### 4.8 3-B 目标类分布：判不出

### 4.9 3-A 分层是否延迟植入（单种子）

### 4.10 其他与综合

- 官方预处理（不标准化、不增强）：攻击更快更强，但干净精度低约 0.10 → 分不开。
- **后门的生命周期**：植入（攻击者所在边缘一开窗就饱和）→ 传播（每次云聚合受害边缘跳升 0.13–0.27，攻击者边缘同时被稀释）→ 周期内洗掉（0.005–0.04 / 有效轮）→ 洗不过灌、逐周期饱和 → 攻击者走后约 200 有效轮褪到底线、留 2–6% 长尾。锯齿与衰减是同一机制的两面（推断）。
- **对阶段三的含义**：防御要从第 1 轮一直开、作用在**云聚合之前**；单更新检测在边缘没有依据 → 先做非检测型防御（上传前加固），再试检测线，并把三层个性化当作防御来检验。

### 5.3 防御线 C：边缘干净集作参照的过滤（「方向 2」，已停止）

**思路**：每台边缘用自己 500 张干净图当「信任锚」给每个上传打分，超阈值丢弃；用绝对阈值、不靠「少数服从多数」（每台边缘每轮只有 2–3 个上传，多数原则成不了簇）。一开始就与三层个性化叠加：共享块管跨边缘灌入，参照过滤管边缘内部的攻击者。
⚠ 更正（F-123）：主线下上传里**也带**统计量（主干训练段末尾的值），只是不下发 → 方向 2 能留在正式口径里做；旧说法「主线统计量不上传」是错的。
文献：最近的先例 **FoggyTrust**（分层、雾节点持根数据跑 FLTrust；针对模型投毒、不个性化、用更新余弦、前提是组内同质）；**SURA**（单服务器、干净图 + 统一 BN 参照，被代理集泄露 + 方向幅度联合调整绕过）→ 阈值只在良性开发 run 上标定、威胁模型写明边缘干净集保密。
划分：因为主划分「组内更同质」很弱（§2.3），方向 2 每组在两个划分上各做一遍：主划分（main）与固定画像 λ = 0.4（homo）。

**第一段：只打分、全部接纳（ERP 种子 42 + 不投毒开发 run ERPB 种子 41，12 run，预注册 N-013）**
- 候选分数（越大越可疑）：**逐客户端参照 KL**（上传统计量的高斯与「该上传权重在干净图上前向算出的矩」之间的逐通道 KL，按层平均：全部层 / stem / 各段）、**类混合残差**（把上传统计量拟合成干净图逐类矩的凸组合后的残差均方根，新设计）、不拟合的残差、缓存池里到其余端的余弦距离中位数。
- 规则：每个划分选「四格（共享块 关 / 开 × 集中 / 分散）AUROC 取最小、再取最大」的分数；阈值 = 开发 run 90% 分位点；最小 AUROC ≥ 0.75 → `feasible`。「记录不改训练」的闸通过（与 SNAP 前 60 轮逐位相同）。

| 划分 | 选中的分数 | 四格最小 AUROC | 四格 AUROC（关·集中 / 关·分散 / 开·集中 / 开·分散） | 阈值 τ（关 / 开） | 判定 |
|---|---|---|---|---|---|
| main | 类混合残差 | **0.847** | 0.999 / 0.847 / 0.998 / 0.904 | 0.1190 / 0.1206 | `feasible` |
| homo | 逐客户端参照 KL（全部层） | **0.895** | 0.973 / 0.922 / 0.964 / 0.895 | 0.00408 / 0.00373 | `feasible` |

- 回放（🔍，单种子）：main 集中几乎全挡，**分散漏网 43% / 23%**；良性误剔 main 5–14%、homo 17–28%（名义 10%；没攻击者的边缘也高 → 开发种子定的绝对阈值搬到种子 42 不准）。零分布在 homo 下不可用；缓存池多数原则最小 AUROC 0.65 / 0.70，弱于选中分数。

**第二段：分数 > 阈值就丢弃（ERF 24 run + 对照 ERC 12 run，种子 42–44，预注册 N-014）**
- 规则：判定量 = 全部良性端池化 ASR；三个种子降幅均值 ≥ 0.15、最差 ≥ 0.10、精度降 ≤ 0.02 → `protects`；ASR 达标精度不达标 → `accuracy_bound`；否则 `no_effect`。组合：过滤 + 隔离 ≤ min(只隔离, 只过滤) − 0.10 → `additive`；差 < 0.05 → `redundant`。

| 格子（main） | 标签 | ASR 降幅 均值 / 最差 | 精度降 | ASR（全部良性端）对照 → 过滤 | 在线：攻击者放行 / 良性误剔 |
|---|---|---|---|---|---|
| 不隔离 · 集中 | `accuracy_bound` | 0.420 / 0.337 | 0.0208 | 0.997 → 0.577 | 0.63 / 0.06 |
| 不隔离 · 分散 | `accuracy_bound` | 0.379 / 0.298 | 0.0236 | 0.986 → 0.607 | 0.46 / 0.11 |
| 隔离 1 块 · 集中 | `no_effect` | 0.112 / −0.052 | 0.0135 | 0.399 → 0.286 | 0.64 / 0.05 |
| 隔离 1 块 · 分散 | **`protects`** | 0.334 / 0.213 | 0.0123 | 0.956 → 0.622 | 0.45 / 0.07 |

- 组合：集中 `additive`（0.286 vs 只隔离 0.399）；分散 `redundant`（0.622 ≈ 只过滤 0.607）。
- 按边缘（不隔离、集中）：受害边缘 0.995 / 0.997 / 0.996 → 0.440 / 0.553 / 0.615（均值 0.536）；**E0 良性端 0.998 / 1.000 / 1.000 → 0.709 / 0.747 / 0.887**——三条防御线里唯一动到 E0 的，但仍高。

**冷启动死锁（homo 四格，`accuracy_bound` ×3 / `no_effect` ×1，全是死锁产物、不作证据）**：12 个过滤 run 的 1200 个边缘轮**全部** 100% 被丢：第 1 轮 KL 中位 0.0087 > τ 0.0041 → 全丢 → 模型停在初始值 → 下一轮分数照样高 → 300 轮从未更新（ASR 0.11–0.15 = 底线，精度 0.39 = 只有私有分类头在学）。用户问「是不是干净集选偏了」——**不是**。开发 run 各阶段分数中位数：

→ 死锁 = 分数选择（homo 恰好选了训练初期是后期 2.5 倍的 KL）+ 全程固定阈值 + 全丢不更新；main 若选 KL 也会死锁。规则漏洞（没有「模型从未训练」的闸）与执行疏漏（第一段没查第 1 轮分数与阈值的关系）照实记录。

**反馈循环：分数滞后于后门**
- 在线读数（🔍，单种子，main 集中 种子 42、只看 E0）：

| | 攻击者分数中位 | E0 良性端分数中位 | 「上一云轮 E0 良性 ASR」与「本轮攻击者分数」的相关 |
|---|---|---|---|
| 不隔离 · 只打分 | 0.205 | 0.101 | 0.07 |
| 不隔离 · 过滤 | **0.095** | 0.096 | **0.57** |
| 隔离 · 只打分 | 0.218 | 0.107 | 0.20 |
| 隔离 · 过滤 | **0.106** | 0.098 | **0.71** |

  同格内放行率与 ASR 负相关（放行 0.86 / 0.36 / 0.67，ASR 0.49 / 0.59 / 0.66）。
- 解释：触发器是有界小扰动；模型没学会后门时触发图片在模型眼里与普通图片差不多 → 统计量几乎不偏；学会之后同一触发器引起强烈内部响应 → 统计量偏移 → 分数高。于是过滤压住后门 → 攻击者看起来正常 → 放行 → 后门回升 → 被拦 → 平衡在 ASR 约 0.3–0.6。推论：只打分的 AUROC 高估在线效果。
- **离线直接证据（P-c，预注册，F-136）**：108 个边缘模型（SNAP 集中 + 分散 + TBS k1-snap × 第 6 / 15 / 60 轮 × 4 台边缘）上，「同一批干净图加触发器前后各 BN 层输入矩的 KL」与「该边缘良性端触发 margin」的合并 Spearman **0.911**；每个种子 0.901 / 0.933 / 0.903；每轮内部 0.780 / 0.890 / 0.882；按轮分层置换 p = 0.0001（不是「两者都随训练变大」）；去掉目标类图片 0.908 → **`feedback_moderate`**，反馈循环证据从「弱」升为「中」。探索性：只看受害边缘 0.845、只看分散 0.900。局限：仍是相关性；偏移测在裸边缘模型上、强度测在客户端评估模型上；同一 run 的 4 台边缘共用生成器。
- **误判分布**（描述性，3 种子合并，只有 main）：从未被丢的良性端（过滤 / 过滤 + 共享块）受害边缘 55% / 62%、E0 60% / 67%、分散 36% / 57%；单个良性端被丢比例最高 0.70 / 0.77、0.38 / 0.41、0.79 / 0.86 → 多数很少被丢、少数被丢一半以上；被误判客户端的共同特征没有分析。
- **停止**（D-134，11-19）：方向 2 不再交作业。

**② 结构核查（D0，F-133）**：CPU 小联邦真跑一个云轮（B = 1 / 2 / 4）全过；真实快照（TBS k1-snap × 第 6 / 15 / 60 轮）：全局上云段 = 四台边缘上云段等权平均（权重 0.25 × 4、相对残差 3.7–3.9e-8、拟合矩阵满秩）；四台边缘上云段两两不同；全局边缘段从未上云；客户端私有部分两两不同。第一次核查的两个盲点（四台边缘上云段完全相同也会通过；只拟合了前 40 万坐标）补强后重跑仍全过 → 结构前提成立。

**③ 代价对照：块数扫描（TBS，集中 × B ∈ {1 存快照, 2, 4} × 3 种子，预注册 D1，F-130）**：D = 精度(B=1) − 精度(B=4)；都 ≥ 0.02 → `b1_meaningful`；都 |D| < 0.01 → `isolation_free`。

| 块数 B | 上云参数比例 | 受害边缘 | E0 良性端 | 精度 | 相对不设防的精度代价 | 陈旧模型精度 |

**④ 威胁边界 [9,1,0,0]（TBH，B ∈ {0, 1} × 3 种子，预注册 D2，F-131）**：

| 不加触发器 | 0.016 / 0.015 / 0.024 |

|差| 都 < 0.10 → **`not_transmitted`**：受害边缘剩下的约 0.3–0.4 就是传过去的那部分后门；「后门其实在、只是触发器迁移不过去」被排除 → 支持「最后一块不上云截住跨边缘传播」。不设防参照：两列都约 1.0，只用 δ 就 0.998–1.000。局限：只测第 60 轮、集中布点、单步 PGD 白盒。重现闸 27 / 27 全过。

**⑥ 「后门主要存在最后一块」未能验证（P-a + 追加，F-134 / F-137）**：
- 第一次 P-a：E0 上只训最后一块 / 只训前面几层 / 训全部主干，6 个清除比例（3 种子 × 第 15 / 60 轮）**全是 0.000** → 规则判 `mainly_earlier_layers`，但**阳性对照（训全部主干）也是 0** → 没有分辨力。原因：沿用 P0 预算（学习率 = 客户端 × 0.1，第 15 轮 0.0055、第 60 轮 0.0009；75 步），权重几乎没动。预注册没写「对照也失败时怎么读」——设计漏洞。
- 追加探针（预注册 N-016，看过第一次之后设计、写于数据之前）：种子 42 只训全部主干扫 12 档，找「两轮都清除 ≥ 0.5 且精度降 ≤ 0.05」的最小一档：

| 档 | 清除比例（第 15 / 60 轮） | 精度降幅 |
|---|---|---|
| 学习率 0.01 / 0.03 的 8 档 | 0.000–0.013 | −0.010 … 0.035 |
| 0.1 · 75 步 · 临时线性头 | 0.992 / 0.728 | 0.426 / 0.248 |
| 0.1 · 300 步 · 临时线性头 | 0.696 / 0.808 | 0.328 / 0.182 |
| 0.1 · 75 步 · 重新初始化头 | 0.025 / 0.034 | 0.074 / 0.056 |
| 0.1 · 300 步 · 重新初始化头 | 0.175 / 0.050 | 0.096 / 0.058 |

  → **`not_removable`**，按规则不交正式作业。后门只在模型被打坏时才消失（E0 良性端干净精度第 15 轮 0.843 → 0.418）。
- 含义：P-a 定位不了后门存在哪一层；论文写这一前提**未验证**，机制只剩 P-b 的直接证据。⚠ 精度崩可能部分来自「新主干 + 没重训的私有分类头」对不上 → **不能**读成「后门与主任务缠在一起」。

**⑦ 待议：云端共享的价值在本设定下偏小（未决，只记录）**：几乎断开云端共享（B = 4）也只差约 0.02 精度，而云端共享正是后门传播通道（0.027 → 0.996）。推测原因（没有数据）：评估只看本地分布；每台边缘约 9400 张训练图、任务简单；机构结构偏弱（边缘之间总变差 0.375）。可选方案（未排期）：A 数据稀缺（每端 100 张 × B ∈ {0, 1, 4}，约 10 GPU 小时）；B 块内切分（上云约 52% / 73%，P-a 没给出依据）；C 跨边缘评估（免训练）；D 只写进论文。措辞底线：不说「B = 1 恰好是最优点」，只说「B = 1 几乎不花精度就压掉约 72% 的跨边缘后门」。
**小结**：攻击者集中时几乎不花精度压掉六七成（B = 2 九成以上）；盲区 = 有攻击者的边缘、分散布点；还没回答 = 知道边缘段的攻击者（§5.7 最小版）。结构本身有先例（ESPerHFL、HPFL，只为精度），卖点是「后门隔离作用」及其边界。

### 5.7 攻击基线（进行中）

- **要回答的两个问题**（预注册 N-015 第七节）：问题一（刻画）比 Bad-PFL 弱的攻击在三层 + FedRep 下能不能植入、能不能跨边缘传播（回答「为什么必须研究 Bad-PFL」）；问题二（泛化）对能传播的攻击，共享块（B = 1）与上传前加固是否仍有效。六种：BadNets、Blended、DBA、Neurotoxin、CerP、IBA。
- **第一档已接线**（11-24，D-141 / F-138）：主实验协议每轮从原始数组按索引重新取数，不读旧 `vanilla` 策略开跑前替换进去的投毒数据集 → 恶意端会静默变成良性端（启动校验一直拒绝）。新策略 `static` 在每个批上投毒：① 每批按逐样本伯努利 0.2 抽（与 Bad-PFL 同一个开关、同一个函数）；② 先增强、再加触发器；③ 与 Bad-PFL 一样强制串行；④ 新起策略名，`vanilla` 只配旧取数路径。
- **触发器参数**：BadNets = 右下角 3×3 白块（像素值 1.0）；Blended = hello_kitty 图以 α = 0.2 混合（训练评估同一 α）；DBA = 官方 4 块局部触发器，每块 1×6 像素（第 0 / 4 行 × 第 0–5 / 9–14 列），10 个攻击者轮流分到 3 / 3 / 2 / 2，评估用 24 像素的并集。
- **与官方的已知偏离**：投毒率、攻击者数、全程投毒、目标类 0、学习率与本地轮数、先增强后加触发器全部同 Bad-PFL 对照（几种攻击之间只差触发器）；**不做 DBA 的更新放大 100 倍**（模型替换是另一种攻击成分，在 FedRep + 每台边缘每轮 2–3 个参与者下会直接炸掉边缘模型）。BadNets / Blended 没有单一的联邦学习官方实现，照通行做法。
- **评估**：静态触发器没有固定评估攻击者 → 服务器退回静态触发器（三类评估点都测试钉住）；冻结触发器列关掉。
- **证据**：本地 Python 3.11 不装 TF 2379 passed / 63 skipped / 3 xfailed；装 tensorflow-cpu 2.15.1 全量 2713 passed / 2 failed（已知的 2 条，无回归）；TF 新测试 11 条全过（含真接线 + 两个反向锚点）。**GPU 上的确定性与显存没有证据**。
- **登记**：ATKP（探路：badnet / badnet 重复 / blended / dba × 种子 42 × 4 云轮；badnet 与重复同配置验 GPU 逐位相同）配置已生成、**待集群提交**；ATK（三种 × 种子 42 × 不设防 × 集中 × 主划分 × 300 有效轮）挂在 ATKP 放行之后。
- **分流规则**（写于数据之前，看末 10 点原始 ASR；路由决定，不是论文结论）：受害边缘良性端 ≥ 0.30 → `propagates` → 第二阶段 {不设防, B = 1, 上传前加固} × 集中 × 3 种子（判定同共享块的 `blocks` 规则，不做分散）；E0 良性端 ≥ 0.30 而受害边缘 < 0.30 → `local_only`；E0 < 0.30 → `no_implant`；后两者补种子 43、44 作问题一的证据。三个种子同一分支才写成结论。静态触发器没有「投毒率 0 的影子攻击者」底线 → 旁附「干净样本被判成目标类的比例」（约 0.011–0.020）作参照。
- **后续几档**（时间盒 2026-12-06，到期没接通的写进局限）：② IBA（主线没有实现，旧草稿早于主实验协议，要照官方代码重写）；②½ **自适应攻击者最小版**：知道最后一块不上云的 Bad-PFL 攻击者（投毒训练时把边缘段梯度置零、生成器照常）× 集中 × B = 1 × 3 种子；闸 = E0 良性端 ≥ 0.5；ΔV = V(自适应) − V(Bad-PFL) 都 ≥ 0.30 → `b1_breached`，都 < 0.10 → `b1_holds`；③ Neurotoxin（掩码方向未证实）/ CerP（触发器训练还读旧数据路径）。

### 5.8 文献定位（11-17 核查；大部分据摘要）

- 没找到同时占「三层结构 + 个性化 + 优化型触发器 + 边缘主导防御」四样的工作。
- 统计量检测：BNGuard（第一个 BN 层滑动均值 / 方差压成 4 个量、K-means）、CCS，都不分层；相近思路 FLARE、CrowdGuard、FL-CLEANER、集中式 BNP（NeurIPS 2022）；统计量本身是攻击面（arXiv 2405.14670）。
- 分层场景后门防御（Yang et al. Sensors 2023、Al-Maslamani 2023、SHIELD）都不用统计量；FoggyTrust、SURA 见 §5.3；AdvPurge 的「层级模型」= 主干 / 分类头切分，不撞车。
- 三层个性化结构有先例（ESPerHFL、HPFL 等）；「在线过滤 → 反馈循环 → 离线高估在线」没找到对应工作。
- 未覆盖：Bad-PFL / CCS 2026-09 之后的被引用、ICLR 2027 投稿（用户本机查）。

### 6.2 不能说的（常见误读）

- ❌「上传前加固清除了后门」→ 没有不投毒的底线实验，只能说「压低」。
- ❌「组内更同质划分下参照过滤把 ASR 降到 0.12，非常有效」→ 冷启动死锁、模型从未训练。
- ❌「统计量聚类是本项目的贡献」→ BNGuard、CCS 已有。
- ❌「主线下 BatchNorm 统计量不上传」→ 上传了，只是不下发给客户端。
- ❌「集中布点下 E0 全是攻击者」→ 15 个良性端 + 10 个攻击者。
- ❌「边缘视角检测更好」→ 判定是没有优势。
- ❌「3-B 差中差显著，说明迁移依赖目标类自然特征」→ floor 差的机械结果。
- ❌ 把 CCS 线的数字与主线直接比较 → 拓扑、统计量、划分、模型四处不同。
- ❌「Multi-Krum / FLAME 在本仓库挡不住 Bad-PFL」→ 没有有效数据（旧方案里 6 个防御格子被作业脚本覆盖成了「不设防」）；本仓库只测了逐坐标中位数。
- ❌「中位数判 `blocks`，所以有效」→ 效应量 0.004–0.105，受害边缘仍 0.89–0.99。
- ❌「代价对照证明三层个性化不只是少共享」→ `inconclusive`，只报 0.018–0.022。
- ❌「三层个性化保护所有良性机构」→ 边缘里有 1 个攻击者就失守。
- ❌「后门主要存在最后一块」/「重训探针说明后门主要在前面的层」→ 两次探针都没有分辨力，这一前提**未验证**。
- ❌「后门与主任务功能缠在一起」→ 追加探针的精度崩可能来自旧分类头与新主干对不上，没有证据区分。
- ❌「反馈循环已被证明」→ 是中等强度的相关性证据。
- ❌「训练后期植入更难」→ 阶段二判 `not_gated`。
- ❌ 把「用户事后接受代价」说成「通过门槛」。
- ❌「静态攻击（BadNets 等）在分层下传不过去 / 传得过去」→ 还没有数据（ATKP 未提交）。

### 6.3 贯穿三个阶段的教训

1. **攻击饱和遮住效应**：不设防时 ASR 0.96–1.0，3-B 判不出，「部分有效」难看清；「不饱和工作点」一直没跑。
2. **离线 / 只记录会高估在线**：离线一次加固预测不了在线加固；只打分的 AUROC 高估在线过滤。防御一介入，攻击者的可观测量会跟着变。
3. **BatchNorm 统计量是双刃剑**：它是唯一强的单更新信号（阶段二 0.90；参照打分 0.85–0.90），CCS 与方向 2 都靠它；但它可零代价伪造，而且只在后门已被学会后才明显偏移。
4. **结构性隔离比检测稳**：共享块不需要识别谁是攻击者，在适用范围（攻击者集中）内比任何检测类方法和中位数都便宜而稳定；它的边界恰好是检测类方法也没解决的两种情形（问题退化成边缘内部的不分层问题，而不分层下已知防御在 Bad-PFL 原文里基本失效）。
5. **「边缘 = 机构、组内更同质」在主划分里体现得很弱**（0.79）；这条假设影响所有「利用边缘」的防御设计。
6. **自检与预注册也会有漏洞**：P-a 没写「阳性对照也失败」的读法、N-014 没有「模型从未训练」的闸、N-011 没给「两个都开」设崩坏线——都照实记录、不改标签。

## 9. 局限

- **数据与模型**：只有 CIFAR-10 + ResNet-10；只有 FedRep 一种个性化方法；目前只有 Bad-PFL 一种攻击有结果（六种基线攻击接线中）。
- **威胁模型**：全部防御读数都在非自适应攻击者下；统计量通道可伪造只有代码证据。
- **种子**：主结论 3 个种子；分散布点加固、CCS 排查、参照打分可分性、3-A 都是单种子。
- **饱和**：攻击接近饱和，多个子实验撞天花板。
- **口径**：新鲜个性化模型低估干净精度（最多 0.094）；k = 2 的精度代价在陈旧口径下超门槛；按类精度没记录。
- **拓扑**：主要是 4 台边缘 × 25 端；边缘数是否改变防御效果没测。
- **机制**：「后门在最后一块」未验证；白盒探针只测第 60 轮、单步。
- **CCS 线**：只在不分层、统计量共享下做；官方代码跑不起来，不可能逐位对拍；仿真主机内存约 31 GiB。
- **判定时序**：三层个性化（G6）与锯齿 / 可观测性（G1）的判定规则写于数据之前、脚本写于部分数据之后；P-a 追加探针是看过第一次结果之后设计的（写于新数据之前）。

## 12. 判定标签的含义

| 标签 | 含义 |
|---|---|
| `protects` / `protects_victims` | ASR 降幅达标且精度代价 ≤ 0.02 |
| `accuracy_bound` | ASR 达标但精度超门槛（离线筛选里 = 削得动的都过不了精度门槛） |
| `no_effect` | ASR 不达标 |
| `marginal` | 筛选阶段的边缘情形 |
| `blocks` / `not_blocks` | 三个种子 ASR 降幅都 > 0 且精度代价 ≤ 0.02（只要求方向）/ 否 |
| `weaker_than_b1` / `comparable_to_b1` / `stronger_than_b1` | 比隔离 1 块高 ≥ 0.10 / 相差 < 0.10 / 低 ≥ 0.10 |
| `self_cleaning` / `no_cleaning` | 有 / 没有周期内自清洁 |
| `not_gated` | 没有收敛门控 |
| `no_edge_gain` / `edge_better` / `undetectable` | 边缘视角没优势 / 更好 / 全局视角也测不出（AUROC < 0.7） |
| `feasible` / `infeasible` | 打分能 / 不能分开攻击者（四格最小 AUROC ≥ 0.75） |
| `partial_repro` / `invalid_no_attack` | 部分复现 / 不设防时攻击都没植入，判定无效 |
| `cluster_alone_sufficient` | 只开聚类就够（5 种子均值） |
| `no_fix` | 缓存池没修好（精度超门槛） |
| `not_established` | 没有确立 |
| `additive` / `redundant` / `partial` | 组合叠加 / 冗余 / 介于其间 |
| `inconclusive` | 三个种子没有同时满足任一分支，报数字不报方向 |
| `b1_meaningful` / `isolation_free` / `isolation_better` | 块数扫描的三条分支（D ≥ 0.02 / \|D\| < 0.01 / D ≤ −0.01） |
| `clean_protected` / `e1_breached` | 干净边缘受保护 / 有 1 个攻击者的边缘失守 |
| `mainly_last_block` / `mainly_earlier_layers` | 重训探针：后门主要在最后一块 / 主要在前面的层（本项目第一次探针判后者，但阳性对照也失败 → 没有分辨力） |
| `not_transmitted` / `trigger_not_transferable` | 白盒探针：后门没传过来 / 触发器迁移不过去 |
| `feedback_moderate` | 统计量偏移随后门强度的证据为「中」 |
| `not_removable` / `uninformative` / `last_block_suffices` / `last_block_insufficient` | 追加探针：在约束内清不掉后门 / 阳性对照不过 / 只训最后一块够 / 不够 |
| `propagates` / `local_only` / `no_implant` | 攻击基线分流：能传播 / 只在本地 / 没植入 |
| `b1_breached` / `b1_holds` | 自适应攻击者突破 / 没突破隔离 1 块 |
| `user_decides` | 落在预注册的两条分支之间，由用户判 |
| `insufficient` / `invalid` | 缺数据 / 有数据但闸不过 |
