# 导师讨论简报：分层联邦学习中的个性化后门攻防（2026-11-23）

> 约 3 页。数字取自仓库的证据台账与预注册判定输出，数据截至 2026-11-19；完整数据与定义见同目录 `REPORT-full-2026-11-23.md`。
> 「a / b / c」三个数依次是随机种子 42 / 43 / 44。ASR = 攻击成功率，默认指**良性客户端**的个性化模型上、只数非目标类样本的值。精度代价门槛统一为 0.02。

## 一句话

后门在三层联邦学习里**只经云聚合跨边缘传播**、边缘内的自清洁追不上灌入；我们试了三条「利用可信边缘」的防御线，**没有一条同时**在分散布点下有效、保护攻击者所在边缘的良性端、精度代价 ≤ 0.02；最便宜也最稳的是一个结构性做法——**三层个性化**（模型最后一个残差块只在边缘内平均、不上云），但它只在攻击者集中在少数边缘时有效。

## 1. 研究问题与进度

系统：云 – 边缘服务器（下称「边缘」）– 客户端；客户端用 FedRep（共享主干 + 私有分类头）；攻击 = Bad-PFL（ICLR 2025，逐样本的小幅对抗扰动触发器，‖·‖∞ ≤ 8/255）；CIFAR-10、ResNet-10、100 个客户端、4 台边缘 × 25 端、10% 恶意客户端。假设边缘可信、各持 500 张干净图片。

| 阶段 | 问题 | 状态 |
|---|---|---|
| 一 攻击刻画 | Bad-PFL 何时植入、能持续多久（不分层） | 完成（在官方代码仓库里） |
| 二 分层机制 | 边缘能看到什么、何时能干预、在哪一层干预 | **完成**：123 个正式 run，约 136 GPU 小时 |
| 三 边缘原生防御 | 用边缘的干净数据与算力防御 | **进行中**：85 个正式 run，≥ 160 GPU 小时；三条防御线都已出结论 |

方法学：与官方实现逐条对齐后的统一口径；同配置同种子跨节点逐位可复现；所有判定规则在看数据之前写好并提交（预注册），默认 3 个种子；事后发现的规则漏洞照实记录、不改标签。

## 2. 阶段二：机制上的五个发现（都是预注册判定，3 个种子）

1. **攻击接近饱和**：不设防时攻击者所在边缘的良性端 0.97–1.0，受害边缘最终 ≥ 0.95。
2. **锯齿**：每次云聚合把受害边缘的 ASR 推高 0.13–0.27；两次云聚合之间受害边缘自己的训练在洗（每周期洗掉 0.11–0.22），但洗掉 < 灌入 → 周期末值逐周期升高、最终饱和。5 个格子里 4 个判「有自清洁」。
3. **没有安全时段**：在训练的任何阶段开始投毒，攻击者所在边缘都立刻饱和（植入难度与训练进度的秩相关 0.1 / 0.0 / −0.3）。攻击者走后约 200 个边缘轮褪到「不投毒也有的底线」（0.04–0.13）附近；不分层的联邦学习一样褪。
4. **边缘视角没有检测优势**：用单个上传更新的范数、余弦、功能分数区分恶意客户端，边缘内归一化与全局归一化的 AUROC 差都 < 0.05。唯一强的信号来自批归一化（BatchNorm）统计量（AUROC 约 0.90），而这个通道攻击者可零代价伪造（代码证据，没有实验）。
5. **三层个性化**：攻击者集中在一台边缘时，受害边缘 ASR 降 0.52（共享最后 1 个残差块）/ 0.73（最后 2 个），精度代价 ≤ 0.02；攻击者所在边缘的良性端不受保护（0.92–1.0）；攻击者分散到每台边缘时几乎无效（降 0.02–0.03，单种子）。

另：一项关于「受害边缘缺目标类样本是否更难被植入」的预注册检验判不出——预注册的差中差「显著」完全来自不投毒底线之差，原始 ASR 都贴着天花板。

## 3. 阶段三：防御线对比

主线设定（分层、统计量私有）下、各自不设防对照的三个种子均值；「E0」= 攻击者所在边缘（15 个良性端 + 10 个攻击者）；集中 = 攻击者全在 E0，分散 = 每台边缘都有攻击者。

| 方法 | 在哪做 | 集中：受害边缘 | 集中：E0 良性端 | 分散：全部良性端 | 精度代价 | 判定 |
|---|---|---|---|---|---|---|
| **三层个性化**（最后 1 块不上云） | 结构，零额外算力 | 0.996 → **0.281** | 0.999 → 0.988 | 0.986 → 0.956 | 0.001 | 旧划分上判「阻断」；新划分复现 |
| **上传前加固**（边缘每云轮末用 500 张干净图做对抗反学习） | 边缘 | 0.996 → 0.588（降 0.48 / 0.52 / 0.23） | 0.999 → 0.982 | 0.998 → 0.713（单种子） | 0.009–0.015；分散 0.030 | 集中「保护受害端」；分散「精度超门槛」 |
| **参照过滤**（边缘用干净图当参照给每个上传的统计量打分，超阈值丢弃） | 边缘，每边缘轮 | 0.996 → 0.536 | 0.999 → **0.781** | 0.986 → 0.607 | 0.021 / 0.024 | 「ASR 达标、精度超门槛」（刚超） |
| 参照过滤 + 三层个性化 | 边缘 + 结构 | 0.281 → 0.184 | 0.988 → 0.801 | 0.956 → 0.622 | 0.012–0.014 | 分散**「保护」**（唯一过全部门槛的一格）；集中：相对只开三层个性化只再降 0.11，单格判「无效」，但组合规则判「叠加」 |

不分层设置（1 台服务器 × 100 端、统计量共享；不能与上表直接比）下复现的 **CCS**（ICASSP 2026：客户端对抗训练 + 服务端按上传统计量聚类剔除）：

| 臂 | ASR（不设防约 0.80–0.95） | 精度代价 | 判定 |
|---|---|---|---|
| 只开聚类（5 个种子） | 降 0.61 / 0.14 / 0.76 / 0.75 / 0.35，均值 0.52 | 约 0.011，很稳 | 「单独就够」但只比门槛 0.5 高 0.02，2 / 5 种子失守 |
| 只开聚类 + 扩大参照池（两个失守种子） | 降 0.78 / 0.79 | 0.026 / 0.028 | 预注册判「没修好」；我看过数据后认为代价可接受（记为事后判断） |
| 带客户端对抗训练（3 个种子） | 降到约 0.1 | 精度 0.39–0.84，训练从第 65–110 轮起随机崩溃 | 不可用 |

**两个方法学发现**（探索性，但对后续设计很关键）：
- **离线 / 只记录的效果高估在线效果**：离线一次性加固预测不了在线加固（在线时每次灌入量几乎没变，效果来自缩小每周期的净增量）；只打分时攻击者与良性端 AUROC 0.85，真过滤后只把 ASR 压到约 0.6。
- **统计量分数可能滞后于后门**：一过滤，攻击者的分数就降到和良性端一样，并跟着「E0 模型被污染的程度」走（相关 0.57 / 0.71，单种子）。解释：小扰动触发器只有在模型学会后门之后才让统计量明显偏移 → 过滤与后门形成反馈循环，停在 ASR 0.3–0.6。

**文献**：「用 BatchNorm 统计量检测恶意客户端」已有 BNGuard（MobiHoc 2025）与 CCS 两篇先例（都不分层）；边缘持根数据的分层防御有 FoggyTrust（针对模型投毒、不个性化、要求组内同质）；三层个性化的结构本身有先例（只为精度）。没找到同时占「三层 + 个性化 + 优化型触发器 + 边缘主导防御」的工作。

## 4. 想和您讨论的问题

1. **论文主张放在哪里？**
   - (A) 以机制刻画（阶段二）+ 结构性隔离（三层个性化）的作用与边界为主，检测 / 加固类防御作为边界与负面结果；
   - (B) 继续找一个「边缘原生」的检测或加固方法。
   - 我的看法：(A) 的证据最强。(B) 三次都撞上同一堵墙：攻击饱和 + 精度门槛 0.02 + 统计量信号可伪造。
2. **三层个性化的威胁模型边界是否可接受？** 它只在「攻击者集中在少数机构」时有效。攻击者分散到每台边缘等于每个机构都有内鬼，这个威胁模型是否需要正面解决？
3. **自适应攻击者先做哪一个？** 对三层个性化，是「只往上云的层写后门」的攻击者；对统计量类方法，是「上传伪造的干净统计量」。前者决定三层个性化能不能成为贡献。
4. **精度门槛 0.02 是否合理？** 多个结果卡在 0.021–0.030：参照过滤 0.021 / 0.024、扩大参照池 0.026 / 0.028、分散布点加固 0.030。如果按 0.03 读，至少参照过滤的两格与扩大参照池会改判。但这只能作为**声明为事后的敏感性分析**，不能改预注册标签。
5. **攻击饱和怎么处理？** 不设防 ASR 0.96–1.0，「部分有效」很难看清。降低投毒率或攻击者比例找一个 ASR 在 0.3–0.8 的工作点，约 6 个 run、5 GPU 小时，计划里有但一直没跑。
6. **泛化性做到什么程度？** 第二种攻击（CerP，可训练触发器）与已知防御基线（Median、Multi-Krum、FLAME 等）是否必须进论文？基线要先修本仓库的 FLAME 实现；而且本仓库至今**没有**这些基线的有效数据（旧的防御格子没开防御）。
7. **种子数**：主结论现在是 3 个种子（原计划主结论 5 个）。
8. **「边缘内更同质」这一假设**：现主线划分里同边缘两端的差异是跨边缘的 0.79 倍，体现很弱。我们做了一个更同质的划分（0.54），三层个性化的效果在两种划分下一致；是否把它定为主线之一？

## 6. 主要局限

只有 CIFAR-10 + ResNet-10 + Bad-PFL；全部防御读数都在「攻击者不知道防御」的前提下；主结论 3 个种子；攻击接近饱和；CCS 只在不分层设置下做（官方代码本身跑不起来，照的是意图）；上传前加固没有不投毒的底线实验，只能说「压低」不能说「清除」。
