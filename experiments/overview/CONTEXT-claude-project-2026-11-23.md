## 1. 项目一句话

三层联邦学习（云 – 边缘服务器 – 客户端；下称「边缘」）里，客户端用个性化方法 FedRep；研究个性化后门攻击 Bad-PFL 的**植入、跨边缘传播、衰减机制**，以及**可信边缘**（持 500 张干净图、有算力）能否成为防御的主角。三个阶段：一 攻击刻画（完成，在 Bad-PFL 官方代码里）→ 二 分层机制（完成）→ 三 边缘原生防御（进行中）。

## 2. 固定设定（速查）

| 项 | 取值 |
|---|---|
| 数据 / 模型 | CIFAR-10 / ResNet-10（对齐 PyTorch 版） |
| 客户端 | 100 个，每端 500 张（375 训练 / 125 留出）；每轮全局 10% 参与 |
| 拓扑 | 4 台边缘 × 25 端；一个云轮 = R 个边缘轮（主线 R = 5）；「有效轮」= 边缘轮累计；主线 60 云轮 = 300 有效轮 |
| 个性化 | FedRep：每轮先训私有分类头 1 epoch，再训共享主干 5 epoch；BatchNorm 滑动统计量**私有**（但上传里也带，只是不下发） |
| 攻击 | Bad-PFL：触发样本 = x + δ（生成器的定向扰动，4/255）+ ξ（一步非定向扰动，4/255）；目标类 = 飞机；10 个恶意端（10%）；投毒率 0.2；**攻击者不知道防御** |
| 布点 | 集中 [10,0,0,0]：攻击者全在边缘 E0（E0 = 15 良性 + 10 攻击者），E1–E3 是受害边缘；分散 [3,3,2,2] |
| 划分 | 现主线 = 机构式设计划分 C1（每台边缘有自己的类比例表，边缘内 Dirichlet 0.5）；「组内同质划分」= 固定客户端画像 λ = 0.4；旧 noniid 划分（早期组与 CCS 线，没有边缘干净集） |
| 主量 | 良性端 ASR（攻击成功率）：良性客户端的「新鲜个性化模型」（当前共享主干 + 自己的私有部分）上，只数非目标类，末 10 个评估点均值。V = 受害边缘，B0 = E0 的良性端，P = 全部良性端池化 |
| 精度 | 同一个新鲜个性化模型的精度；**精度代价门槛 0.02** |
| 底线（floor） | 攻击者在场但不投毒时同一触发器的 ASR，约 0.04–0.13 |
| 纪律 | 预注册判定；默认 3 个种子（42–44）；同配置同种子逐位可复现；标签事后不改；机时上限约 100 GPU 小时 / 周 |

## 4. 阶段二结论速查（全部预注册、3 个种子，除非注明）

| 子问题 | 结论 | 关键数字 |
|---|---|---|
| 攻击强度 | 接近饱和 | E0 良性端 0.97–1.0；受害边缘最终 ≥ 0.95 |
| 平台期是不是对抗扰动本身 | 不是 | floor 0.04–0.10 < 判据 0.3；floor 随本边缘目标类占比变 |

| 边缘视角能否更好地检测 | 不能（`no_edge_gain` / `undetectable`） | 范数 AUROC 0.71–0.85、边缘 − 全局 < 0.05；余弦与功能分数 0.50–0.64；BatchNorm 统计量部分 0.90（可伪造） |
| 三层个性化（旧划分） | 集中 `blocks`；分散无效 | 受害边缘降 0.524（k=1）/ 0.730（k=2）；精度代价 ≤ 0.02；E0 良性端 0.92–1.0 |
| 目标类分布（3-B） | 判不出（天花板下的机械结果） | 差中差 +0.070，完全来自 floor 之差 |
| 分层是否延迟植入（3-A） | 只有单种子，非单调 | 比值 2 台 0.77、4 台 0.51、10 台 2.97 |

## 5. 阶段三结论速查

**三层个性化**（最后 1 个残差块只在边缘内平均、不上云；新划分、不设防、3 种子均值）：

| 划分 · 布点 | 良性端 ASR 关 → 开 | 受害边缘 | E0 良性端 | 精度 |
|---|---|---|---|---|
| 现主线 · 集中 | 0.997 → 0.399 | 0.996 → 0.281 | 0.999 → 0.988 | 0.868 → 0.867 |
| 现主线 · 分散 | 0.986 → 0.956 | — | — | 0.869 → 0.867 |
| 组内同质 · 集中 | 0.926 → 0.418 | 0.911 → 0.302 | 0.999 → 1.000 | 0.844 → 0.845 |
| 组内同质 · 分散 | 0.977 → 0.990 | — | — | 0.844 → 0.844 |

**防御线 A：上传前加固**（边缘每云轮末用 500 张干净图做 SAU 对抗反学习）：
- 离线筛选 36 种配置：`accuracy_bound`（能削掉灌入的都精度超标；最接近的 SAU ε=8/255 削减 0.58 / 0.44、精度降 0.032 / 0.023）。
- 在线、集中：受害端 0.995 → 0.519 / 0.997 → 0.475 / 0.996 → 0.769（降 0.476 / 0.522 / 0.228），精度降 0.009 / 0.013 / 0.015 → `protects_victims`；E0 良性端 `no_effect`；灌入量几乎不变（比值 0.79 / 1.01 / 0.96），效果来自缩小每周期净增量（探索性）。
- 在线、分散（单种子）：0.998 → 0.713，精度降 0.030 → `marginal`。开销：训练墙钟 +116%。

**防御线 B：CCS**（客户端对抗训练 + 服务端按上传的 BatchNorm 统计量聚类剔除；**只在不分层、统计量共享下做**）：
- 统计量私有时 FedRep + CCS 主任务崩坏（客户端私有统计量与新主干失配）；改共享后不崩。
- 两个都开（种子 42）：ASR 降 0.684、精度降 0.112 → `partial_repro`。
- 只开聚类 5 种子：ASR 降 0.614 / 0.139 / 0.762 / 0.753 / 0.345（均值 0.523），精度降约 0.011 → `cluster_alone_sufficient`，但刚过线、2 / 5 失守。
- 带对抗训练：训练从第 65–110 轮起随机崩溃。
- 缓存池（两个失守种子）：ASR 降 0.779 / 0.794，精度降 0.026 / 0.028 → `no_fix`；用户事后认为代价可接受。
- 「统计量共享本身削弱后门」：均值 0.085 < 0.10 → `not_established`。

**防御线 C：参照过滤**（边缘用干净图当参照，给每个上传的统计量打分，超阈值丢弃）：
- 只打分：AUROC 四格最小 0.847（现主线）/ 0.895（组内同质）→ `feasible`；分散布点漏网 43% / 23%。
- 真过滤（现主线，3 种子）：

| 格子 | 标签 | ASR 降幅均值 / 最差 | 精度降 | ASR 对照 → 过滤 |
|---|---|---|---|---|
| 三层个性化关 · 集中 | `accuracy_bound` | 0.420 / 0.337 | 0.0208 | 0.997 → 0.577 |
| 三层个性化关 · 分散 | `accuracy_bound` | 0.379 / 0.298 | 0.0236 | 0.986 → 0.607 |
| 三层个性化开 · 集中 | `no_effect` | 0.112 / −0.052 | 0.0135 | 0.399 → 0.286（与三层个性化组合判 `additive`） |
| 三层个性化开 · 分散 | **`protects`** | 0.334 / 0.213 | 0.0123 | 0.956 → 0.622 |

- 集中布点过滤把 E0 良性端从约 1.0 压到 0.71 / 0.75 / 0.89（三条线里唯一动到 E0 的，但仍高）。
- 组内同质划分：**冷启动死锁**（第 1 轮所有上传都超阈值 → 全扔 → 模型 300 轮从未更新），**不提供证据**；原因 = 所选分数训练初期是后期 2.5 倍 + 全程固定阈值 + 全扔不更新，与干净集无关。
- 机制（探索性，相关性证据）：分数可能**滞后于后门**——过滤后攻击者分数降到与良性端相同，并跟着 E0 被污染程度走（相关 0.57 / 0.71）→ 反馈循环，ASR 停在 0.3–0.6。

**文献定位**：统计量检测有先例（BNGuard、CCS，都不分层）；边缘持根数据的分层防御有 FoggyTrust（模型投毒、不个性化、要求组内同质）；三层个性化的结构有先例（ESPerHFL、HPFL，只为精度）；没找到「三层 + 个性化 + 优化型触发器 + 边缘主导防御」四样全占的工作。

## 6. 常见误读（不要这样说）

- ❌「上传前加固清除了后门」→ 没有不投毒的底线实验，只能说「压低」。
- ❌「组内同质划分下参照过滤把 ASR 降到 0.12，非常有效」→ 冷启动死锁、模型没训练。
- ❌「统计量聚类是本项目的贡献」→ 已有先例。
- ❌「主线下 BatchNorm 统计量不上传」→ 上传了，只是不下发。
- ❌「集中布点下 E0 全是攻击者」→ 15 良性 + 10 攻击者。
- ❌「边缘视角检测更好」→ 判定是没有优势。
- ❌「3-B 差中差显著，说明迁移依赖目标类自然特征」→ floor 差的机械结果。
- ❌ 把 CCS 线的数字与主线直接比较 → 拓扑、统计量、划分、模型四处不同。
- ❌「Median / Multi-Krum 在本仓库挡不住 Bad-PFL」→ 本仓库没有这些基线的有效数据（旧防御格子实际没开防御）；文献里 flat 设定下它们挡不住。
- ❌「训练后期植入更难」→ 阶段二判 `not_gated`。
- ❌ 把「用户事后接受代价」说成「通过门槛」。

## 9. 判定标签的含义

`protects` / `protects_victims` = 达到 ASR 门槛且精度代价 ≤ 0.02；`accuracy_bound` = ASR 达标但精度超门槛；`no_effect` = ASR 不达标；`marginal` = 筛选阶段的边缘情形；`blocks` = 三层个性化的阻断判定；`self_cleaning` = 有自清洁；`not_gated` = 没有收敛门控；`no_edge_gain` / `undetectable` = 边缘视角没优势 / 全局视角也测不出；`feasible` = 打分能分开攻击者；`partial_repro` = 部分复现；`cluster_alone_sufficient` = 只开聚类就够；`no_fix` = 没修好；`not_established` = 没有确立；`additive` / `redundant` = 组合叠加 / 冗余；`user_decides` = 落在预注册的两条分支之间，由用户判。
