## 1. 项目一句话

三层联邦学习（云 – 边缘服务器 – 客户端；下称「边缘」）里，客户端用个性化方法 FedRep；研究个性化后门攻击 Bad-PFL 的**植入、跨边缘传播、衰减机制**，以及**可信边缘**（持 500 张干净图、有算力）能否成为防御的主角。三个阶段：一 攻击刻画（完成，在 Bad-PFL 官方代码里）→ 二 分层机制（完成）→ 三 边缘原生防御（收尾）。**2026-11-19 起不再开新方向，转入学位论文整合。**

**论文一句话叙事**：优化型后门是在**云聚合那一刻**跨边缘扩散的（每个云周期「灌入 − 洗掉」的竞赛）；边缘看不出谁在投毒，但它站在云聚合之前、本身是机构边界 → **防御的杠杆在机构之间的边界上，而不在机构内部**。
RQ1 后门怎样植入 / 扩散 / 衰减；RQ2 边缘能看到什么、何时能干预；RQ3 边缘侧能做什么防御、边界与代价。假设 H1（边缘内更同质 → 边缘视角检测更强）否定；H2（后期开始的攻击更难植入）否定；H3（私有分类头 + 私有统计量挡住 Bad-PFL）只有反面信号。
贡献：C1 机制刻画 + 灌入—洗掉分解；C2 否定结果（边缘视角无检测优势）；C3 两条非检测型边缘防御（三层个性化砍灌入、上传前加固压净增量）+ 检测型对照（统计量参照过滤），统一比较 + 有效边界；C4 预注册 + 逐位复现的协议。

## 5. 阶段三结论速查

**三层个性化**（论文里叫「边缘级共享块」；最后 B 个残差块只在边缘内平均、不上云；新划分、不设防、3 种子均值；下表 B = 1）：

| 划分 · 布点 | 良性端 ASR 关 → 开 | 受害边缘 | E0 良性端 | 精度 |
|---|---|---|---|---|
| 现主线 · 集中 | 0.997 → 0.399 | 0.996 → 0.281 | 0.999 → 0.988 | 0.868 → 0.867 |
| 现主线 · 分散 | 0.986 → 0.956 | — | — | 0.869 → 0.867 |
| 组内同质 · 集中 | 0.926 → 0.418 | 0.911 → 0.302 | 0.999 → 1.000 | 0.844 → 0.845 |
| 组内同质 · 分散 | 0.977 → 0.990 | — | — | 0.844 → 0.844 |

- 块数扫描（集中，B = 0 / 1 / 2 / 4，上云参数 100% / 25.1% / 6.4% / 0.14%）：受害边缘 0.996 / 0.281 / 0.046 / 0.027，E0 良性端都约 1.0，精度代价 — / 0.002 / 0.010 / 0.022。预注册量 = 精度(B=1) − 精度(B=4) = 0.0202 / 0.0223 / 0.0182 → `inconclusive`（种子 44 差一点没到 0.02），**只报数字不报方向**。
- 威胁边界 [9,1,0,0]：干净边缘降 0.683 / 0.649 / 0.608（`clean_protected`）；只有 1 个攻击者的 E1 良性端 0.931 / 0.999 / 0.941（`e1_breached`）→ **隔离是按边缘的**，事先预测、被检验。
- 机制：前半程每次云聚合的灌入按 ASR 砍到 1/3–1/6、按 margin 约一半 → 它是砍灌入的防御。
- 结构核查：小联邦与真实快照第一次都过；核查本身补强后待重跑（暂定）。

**已知防御基线：逐坐标中位数**（三层个性化关）：边缘层中位数集中布点受害边缘降 0.004 / 0.050 / 0.004、分散降 0.025–0.043；云层中位数集中降 0.047 / 0.105 / 0.030、分散 ≈ 0。三格判 `blocks`（规则只要求方向一致 + 精度代价 ≤ 0.02），云层分散 `not_blocks`；受害边缘仍 0.89–0.99，集中布点 `weaker_than_b1`；每周期灌入不变。

**统一对比**（现主线、集中、3 种子；受害边缘 / E0 良性端 / 精度代价）：不设防 0.996 / 0.999 / —；三层个性化 0.281 / 0.988 / 0.002；上传前加固 0.587 / 0.983 / 0.012；参照过滤 0.536 / 0.781 / 0.021；参照过滤 + 三层个性化 0.184 / 0.800 / 0.015；边缘层中位数 0.976 / 1.000 / 0.002；云层中位数 0.935 / 0.998 / 0.001。描述性，不是判定。

**防御线 A：上传前加固**（边缘每云轮末用 500 张干净图做 SAU 对抗反学习）：
- 离线筛选 36 种配置：`accuracy_bound`（能削掉灌入的都精度超标；最接近的 SAU ε=8/255 削减 0.58 / 0.44、精度降 0.032 / 0.023）。
- 在线、集中：受害端 0.995 → 0.519 / 0.997 → 0.475 / 0.996 → 0.769（降 0.476 / 0.522 / 0.228），精度降 0.009 / 0.013 / 0.015 → `protects_victims`；E0 良性端 `no_effect`；按 ASR 口径灌入几乎不变（比值 0.79 / 1.01 / 0.96），按 margin 口径灌入也降约三分之一 → 措辞「**主要不是**靠砍灌入」，效果主要来自缩小每周期净增量（探索性）。
- 在线、分散（单种子）：0.998 → 0.713，精度降 0.030 → `marginal`。开销：训练墙钟 +116%。

**防御线 B：CCS**（客户端对抗训练 + 服务端按上传的 BatchNorm 统计量聚类剔除；**只在不分层、统计量共享下做**）：
- 统计量私有时 FedRep + CCS 主任务崩坏（客户端私有统计量与新主干失配）；改共享后不崩。
- 两个都开（种子 42）：ASR 降 0.684、精度降 0.112 → `partial_repro`。
- 只开聚类 5 种子：ASR 降 0.614 / 0.139 / 0.762 / 0.753 / 0.345（均值 0.523），精度降约 0.011 → `cluster_alone_sufficient`，但刚过线、2 / 5 失守。
- 带对抗训练：训练从第 65–110 轮起随机崩溃。
- 缓存池（两个失守种子）：ASR 降 0.779 / 0.794，精度降 0.026 / 0.028 → `no_fix`；用户事后认为代价可接受。
- 「统计量共享本身削弱后门」：均值 0.085 < 0.10 → `not_established`。

**防御线 C：参照过滤**（边缘用干净图当参照，给每个上传的统计量打分，超阈值丢弃）：
- 只打分：AUROC 四格最小 0.847（现主线）/ 0.895（组内同质）→ `feasible`；分散布点漏网 43% / 23%。
- 真过滤（现主线，3 种子）：

| 格子 | 标签 | ASR 降幅均值 / 最差 | 精度降 | ASR 对照 → 过滤 |
|---|---|---|---|---|
| 三层个性化关 · 集中 | `accuracy_bound` | 0.420 / 0.337 | 0.0208 | 0.997 → 0.577 |
| 三层个性化关 · 分散 | `accuracy_bound` | 0.379 / 0.298 | 0.0236 | 0.986 → 0.607 |
| 三层个性化开 · 集中 | `no_effect` | 0.112 / −0.052 | 0.0135 | 0.399 → 0.286（与三层个性化组合判 `additive`） |
| 三层个性化开 · 分散 | **`protects`** | 0.334 / 0.213 | 0.0123 | 0.956 → 0.622 |

- 集中布点过滤把 E0 良性端从约 1.0 压到 0.71 / 0.75 / 0.89（三条线里唯一动到 E0 的，但仍高）。
- 组内同质划分：**冷启动死锁**（第 1 轮所有上传都超阈值 → 全扔 → 模型 300 轮从未更新），**不提供证据**；原因 = 所选分数训练初期是后期 2.5 倍 + 全程固定阈值 + 全扔不更新，与干净集无关。
- 机制（探索性，相关性证据）：分数可能**滞后于后门**——过滤后攻击者分数降到与良性端相同，并跟着 E0 被污染程度走（相关 0.57 / 0.71）→ 反馈循环，ASR 停在 0.3–0.6。

**文献定位**：统计量检测有先例（BNGuard、CCS，都不分层）；边缘持根数据的分层防御有 FoggyTrust（模型投毒、不个性化、要求组内同质）；三层个性化的结构有先例（ESPerHFL、HPFL，只为精度）；没找到「三层 + 个性化 + 优化型触发器 + 边缘主导防御」四样全占的工作。

## 6. 常见误读（不要这样说）

- ❌「上传前加固清除了后门」→ 没有不投毒的底线实验，只能说「压低」。
- ❌「组内同质划分下参照过滤把 ASR 降到 0.12，非常有效」→ 冷启动死锁、模型没训练。
- ❌「统计量聚类是本项目的贡献」→ 已有先例。
- ❌「主线下 BatchNorm 统计量不上传」→ 上传了，只是不下发。
- ❌「集中布点下 E0 全是攻击者」→ 15 良性 + 10 攻击者。
- ❌「边缘视角检测更好」→ 判定是没有优势。
- ❌「3-B 差中差显著，说明迁移依赖目标类自然特征」→ floor 差的机械结果。
- ❌ 把 CCS 线的数字与主线直接比较 → 拓扑、统计量、划分、模型四处不同。
- ❌「Multi-Krum 在本仓库挡不住 Bad-PFL」→ 没有有效数据（旧防御格子实际没开防御）；本仓库只测了逐坐标中位数（几乎无效）。
- ❌「中位数判 `blocks`，所以有效」→ 效应量 0.004–0.105，受害边缘仍 0.89–0.99。
- ❌「代价对照证明三层个性化不只是少共享」→ `inconclusive`，只报 0.018–0.022。
- ❌「三层个性化保护所有良性机构」→ 边缘里有 1 个攻击者就失守。
- ❌「训练后期植入更难」→ 阶段二判 `not_gated`。
- ❌ 把「用户事后接受代价」说成「通过门槛」。

## 9. 判定标签的含义

`protects` / `protects_victims` = 达到 ASR 门槛且精度代价 ≤ 0.02；`accuracy_bound` = ASR 达标但精度超门槛；`no_effect` = ASR 不达标；`marginal` = 筛选阶段的边缘情形；`blocks` = 三层个性化的阻断判定；`self_cleaning` = 有自清洁；`not_gated` = 没有收敛门控；`no_edge_gain` / `undetectable` = 边缘视角没优势 / 全局视角也测不出；`feasible` = 打分能分开攻击者；`partial_repro` = 部分复现；`cluster_alone_sufficient` = 只开聚类就够；`no_fix` = 没修好；`not_established` = 没有确立；`additive` / `redundant` = 组合叠加 / 冗余；`inconclusive` = 三个种子没有同时满足任一分支，报数字不报方向；`clean_protected` / `e1_breached` = 干净边缘受保护 / 有 1 个攻击者的边缘失守；`weaker_than_b1` / `comparable_to_b1` = 比隔离 1 块弱 ≥ 0.10 / 相差 < 0.10；`user_decides` = 落在预注册的两条分支之间，由用户判。
